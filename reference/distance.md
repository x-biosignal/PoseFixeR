# Euclidean distance between two keypoints

Euclidean distance between two keypoints

## Usage

``` r
distance(dat, a, b, time)
```

## Arguments

- dat:

  Reshaped keypoint data (see
  [`reshaping()`](https://x-biosignal.github.io/PoseFixeR/reference/reshaping.md)).

- a, b:

  Keypoint indices or names.

- time:

  Frame index or vector of frames.

## Value

The distance(s) between keypoints `a` and `b`.
