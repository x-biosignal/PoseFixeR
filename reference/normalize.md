# Normalizing coordinates from OpenPose

Normalizing coordinates from OpenPose

## Usage

``` r
normalize(obj)
```

## Arguments

- obj:

  A list of per-frame keypoint matrices (from
  [`import_json()`](https://x-biosignal.github.io/PoseFixeR/reference/import_json.md)).

## Value

The neck-normalised keypoint data.
