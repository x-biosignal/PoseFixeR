# Title Plotting frames of gait cycle

Title Plotting frames of gait cycle

## Usage

``` r
diplay_frames(obj, layout = c(5, 5), xlim = c(450, 800), ylim = c(700, 200))
```

## Arguments

- obj:

  list for reshaped object

- layout:

  vector indicating layout for display

- xlim:

  vector of 2 elements

- ylim:

  vector of 2 elements

## Value

null
